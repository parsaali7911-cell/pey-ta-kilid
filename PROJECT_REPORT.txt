۱) محصول چیست؟
--------------------------------------------------------------------------------
پی‌تا‌کلید یک مارکت‌پلیس B2B برای مصالح و خدمات ساختمانی است. کاربر از یک
جستجوی آزاد (متن / عکس / صدا) مسیرهای زیر را باز می‌کند:

  • خرید کالا
  • فروش / عرضه (فروشنده شو)
  • پیدا کردن متخصص ساختمانی
  • ثبت‌نام به‌عنوان متخصص
  • طراحی / تصویرسازی محصول در فضای واقعی کاربر

زبان‌های رابط کاربری:
  • فارسی (پیش‌فرض، راست‌به‌چپ / RTL)
  • انگلیسی
  • عربی

۲) معماری و پشتهٔ فنی
--------------------------------------------------------------------------------
ساختار Monorepo:
  • apps/api     → NestJS 11 + Prisma 6 + PostgreSQL + Redis + JWT
  • apps/web     → Next.js 15 + React 19 + TypeScript (App Router)
  • packages/shared-types
  • packages/config (اعتبارسنجی env با Zod)

زیرساخت:
  • Docker Compose: PostgreSQL 16 + Redis 7
  • Node.js >= 20 · npm workspaces
  • آپلود فایل‌ها از مسیر /api/uploads/*
  • AI اختیاری: OpenAI (vision / image / voice / translation)
  • ERP: Outbox آماده؛ کلاینت ERPNext هنوز پیاده نشده (none | memory)

آمار تقریبی:
  • مدل‌های Prisma: ۴۴
  • Migrationها: ۱۶
  • Controllerهای Nest: حدود ۲۲
  • صفحات اصلی locale وب: ۱۳ مسیر
  • استان‌ها / شهرها: ۳۱ / حدود ۳۸۷
  • دسته‌های مصالح (lexicon): ۳۳
  • تخصص‌های ساختمانی: ۵۹

--------------------------------------------------------------------------------
۳) آنچه ساخته شده — دامنه به دامنه
--------------------------------------------------------------------------------

۳.۱ احراز هویت و سازمان‌ها
  • ثبت‌نام / ورود / تازه‌سازی توکن / خروج / me
  • نقش پلتفرم: SUPER_ADMIN · ADMIN · SUPPORT · FINANCE · USER
  • نقش سازمان: ORG_OWNER · ORG_ADMIN · ORG_STAFF · ORG_VIEWER
  • قابلیت سازمان: canSell · canBuy · isProfessional + تخصص اصلی
  • صفحات: /login · /register?intent=seller|professional|buyer

۳.۲ کاتالوگ و Listing
  • درخت Category با واحد اندازه‌گیری (UoM) پیش‌فرض هر برگ + Attribute وابسته
  • Product / Variant / Listing / Media / AttributeValue
  • جریان وضعیت: Draft → Pending Review → Approved → Published
  • ویزارد ۶مرحله‌ای فروشنده + ویرایش Listing + آپلود رسانه
  • صفحات: /catalog · /catalog/[slug]

۳.۳ جستجو و Intent
  • Intent قاعده‌محور (بدون اجبار به LLM): خرید / فروش / متخصص / طراحی
  • جستجوی متنی روی کاتالوگ منتشرشده + فیلتر مکان / بودجه / ویژگی
  • جستجوی تصویری و صوتی (وقتی AI_PROVIDER=openai)
  • لکسیکون ایران: ۳۱ استان · ~۳۸۷ شهر · ۳۳ دسته · ۵۹ تخصص
  • صفحه: /search + نوار جستجو در هدر سایت

۳.۴ قیمت، انبار، RFQ، پیشنهاد، سفارش، پرداخت
  • قیمت Listing با حاشیه / FX (بدون افشای supplierCost به عموم)
  • موجودی: ورود / خروج / رزرو / آزادسازی + دفتر کل
  • جریان تجاری: RFQ خریدار → Quote فروشنده → Order
  • پرداخت دستی حواله بانکی + تأیید ادمین (درگاه آنلاین هنوز نیست)
  • پنل خریدار: تب‌های RFQ / Quote / Order

۳.۵ متخصصان (ویژگی بزرگ اخیر)
  • دایرکتوری با فیلتر شهر / تخصص / فاصله و مرتب‌سازی با رتبه پروفایل
  • ثبت‌نام سریع: نام نمایشی + تخصص + شهر + موبایل + کد ملی
  • تأیید هویت:
      - OTP موبایل
      - کد ملی (checksum ایرانی + ذخیره hash با SHA-256؛ فقط ۴ رقم آخر عمومی)
      - عکس پروفایل
  • رتبه پروفایل ۰ تا ۱۰۰:
      - موبایل تأییدشده: ۲۰
      - کد ملی: ۱۵
      - عکس: ۱۵
      - بقیه از تکمیل بیو / سابقه / قیمت / شعاع خدمت / نمونه کار و …
  • identityVerified وقتی موبایل + کد ملی + عکس کامل باشد
  • نمونه کار (portfolio)
  • نظرات مشتری:
      - مهمان → وضعیت PENDING تا تأیید ادمین
      - کاربر لاگین‌شده → APPROVED خودکار
  • صفحات: /professionals · /professionals/[slug]
  • لید مشتری + claim/close در پنل فروشنده/متخصص

۳.۶ طراح فضا (Designer)
  • آپلود عکس فضا + انتخاب Listing واقعی از کاتالوگ
  • تولید تصویر با OpenAI Image وقتی AI فعال باشد
  • صفحه: /designer

۳.۷ SEO چندزبانه
  • تولید خودکار عنوان/توضیح Listing و پروفایل متخصص (بدون LLM)
  • Sitemap / robots / hreflang برای fa | en | ar
  • JSON-LD محصول بدون نشت دادهٔ خصوصی (مثل هزینه تأمین)

۳.۸ پنل‌ها
  • ادمین   /admin   → صف Listing، تأیید پرداخت، لید متخصص، وضعیت AI، taxonomy
  • فروشنده /seller  → سازمان، انبار/موقعیت، Listing، تجارت، تب متخصص
  • خریدار  /buyer   → RFQ، Quote، Order، پرداخت

۳.۹ خانه / مارکت‌پلیس
  • هیرو با جستجوی آزاد + مسیرهای ورود (کاتالوگ / نیاز / متخصص / فروشنده)
  • کارت Listing با قیمت عمومی و لینک «در فضای من»
  • تم بصری طلایی/تیل، فونت فارسی Estedad / Vazirmatn

۳.۱۰ طراحی موبایل (اعمال‌شده)
  • Viewport استاندارد + safe-area برای گوشی‌های notch
  • منوی همبرگری + جستجوی موبایل در هدر
  • گریدها و فرم‌های پنل تک‌ستونه زیر ۷۲۰px
  • تب‌های پنل با اسکرول افقی لمسی
  • هدف لمسی حداقل ۴۴px
  • فونت ۱۶px روی input برای جلوگیری از زوم خودکار iOS
  • فایل سراسری: apps/web/app/styles/peytakilid-mobile.css

۸) عمداً باقی‌مانده / کارهای بعدی
--------------------------------------------------------------------------------
  1) درگاه پرداخت آنلاین واقعی (الان فقط حواله بانکی + تأیید ادمین)
  2) کلاینت ERPNext برای حسابداری (تصمیم: بعد از استقرار سرور)
  3) SMS تولیدی برای OTP (در محیط غیرپروداکشن فعلاً devCode برمی‌گردد)
  4) پنل اختصاصی نقش‌های SUPPORT و FINANCE
  5) PWA / نصب روی موبایل (اختیاری)

--------------------------------------------------------------------------------
۹) خلاصهٔ یک‌خطی برای تحلیلگر
--------------------------------------------------------------------------------
پی‌تا‌کلید یک مارکت‌پلیس ساختمانی چندزبانه است با کاتالوگ واقعی، جستجوی
هوشمند قاعده‌محور، مسیر تجاری RFQ→Quote→Order، پنل فروشنده/خریدار/ادمین،
متخصصان با هویت (موبایل+کدملی+عکس) و رتبه ۱۰۰ و نظرات، طراح فضا با OpenAI،
SEO خودکار، و UI موبایل‌محور؛ ERPNext و درگاه پرداخت آنلاین هنوز باز هستند.
